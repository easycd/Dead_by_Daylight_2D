# 데바데2D — 어둠 속의 추격

Dead by Daylight의 일반 1대4 경기 흐름을 2D 브라우저 온라인 게임에 적용한 오리지널 프로토타입입니다. 원작의 캐릭터·그래픽·음원을 사용하지 않습니다.

최신 규칙 변경은 [RULE_PARITY_IMPLEMENTATION.md](RULE_PARITY_IMPLEMENTATION.md)를 기준으로 합니다. 공격 회복·런지·운반 공격·몸막기·스킬 체크·구출 보호·빈사 탈출을 보완하고 열쇠·지도·아이템 교환·갈고리 파괴·토템·까마귀·대체 봇을 추가했습니다. 과거 설명과 다른 시간·조건은 이 문서에 기록했습니다. 현재 기본 아이템은 5종, 공포 범위 32m, 구출 보호 10초입니다.

현재 공개 주소: https://playgame-7uh4.onrender.com/dbd/
오목: https://playgame-7uh4.onrender.com/
소스: https://github.com/easycd/NIGHTFALL

## 실행

Node.js 20 이상. `npm ci`, `npm start` 후 http://localhost:3002/dbd/ 에 접속합니다. 방장은 기본 살인마이며 대기실에서 역할을 선택할 수 있습니다. 기본 정원 5명(살인마 1 + 생존자 4), 최소 생존자 2명, 최대 16명입니다. 작은 방은 인원에 맞게 발전기 수와 목표를 줄입니다: 생존자 2명은 5개 중 3개, 3명은 6개 중 4개, 4명 이상은 7개 중 5개.

| Space | 파레트 내리기·창문/파레트 넘기·캐비넷·스킬 체크·관전 전환 |

## 규칙

- 살인마 기본 이동은 달리는 생존자의 1.15배. 직접 공격 2회로 건강 → 부상 → 빈사. 공격 방향·거리·벽·파레트·재사용 시간은 서버가 검증합니다. 공격 성공 후 회복 2.7초, 실패 1.5초, 피격 생존자 1.8초 거리 확보 보너스.
- 생존자 걷기 96, 달리기 170, 웅크리기 48 px/s. 살인마 195.5 px/s. 벽 시야 차단, 달리기 흔적·피·소음·심장 박동을 표시합니다. 시야 반경 600px는 2D 화면에 맞춘 값이며 원작 카메라와 동일하지 않습니다.
- 단독 발전기 수리 90초. 중단 진행 저장. 협동은 추가 생존자당 각 작업자의 속도에 15% 페널티를 적용해 합산합니다. 스킬 체크 대성공 +1%, 실패 -10%와 소음.
- 발전기 손상 1.8초, 즉시 -5%·초당 0.25 퇴행. 5% 수리하면 퇴행 중지. 발전기당 최대 8회 손상.
- 빈사 상태에서 정지하면 95%까지 자동 회복. 동료 치료로 부상 상태에서 일어납니다. 동료 치료 기본 16초/체력 한 단계, 빈사 출혈 누적 240초.
- 들어 올리기 2.5초, 갈고리 걸기 1.5초. 운반 저항 스킬 체크 성공을 유지하면 저항이 누적돼 풀려납니다. 파레트·손전등 구출 가능.
- 갈고리 단계당 70초, 시간·재감금으로 단계 누적, 3단계 희생. 동료 구출 1초, 중단 시 초기화. 구출 후 15초 보호·10% 이동 보너스. 작업 시 보호 해제. 보호 중 피격하면 깊은 상흔; E 10초로 치유합니다.
- 캠핑 방지는 7초 유예 후 가까운 살인마와 주변 생존자 여부로 계산합니다. 시간에 따라 게이지가 빨라지며 가득 차면 R로 자력 구출합니다. 출구 전력·종반에는 비활성화됩니다. 희생에 쓰인 갈고리는 60초 사용할 수 없습니다.
- 파레트 2초 기절·양쪽 걷기 차단·생존자 넘기. 살인마 파괴 2.34초. 창문 넘기는 생존자 달리기 0.5초/걷기 1.5초, 살인마 1.7초. 추격 중 같은 창문 3회 넘으면 그 생존자에게 30초 봉쇄. 부상 생존자가 창문을 넘는 중 공격 범위에 잡히면 운반될 수 있습니다.
- 추격을 지속하면 15/25/35초에 살인마 추격 가속이 쌓이고, 명중·파레트 파괴로 초기화합니다.
- 발전기 목표 완료 후 출구를 E 20초로 개방합니다. 출구 진행은 저장됩니다. 열리지 않은 문에서는 탈출할 수 없습니다.
- 마지막 생존자 한 명이면 해치 개방. 살인마는 닫아 출구 스위치를 활성화할 수 있습니다. 출구 개방/해치 폐쇄로 종반 120초 시작, 빈사·갈고리 생존자가 있으면 절반 속도. 만료 시 남은 생존자 탈락.
- 마지막 빈사 생존자, 또는 2명 남아 다른 한 명이 갈고리 2단계일 때 살인마가 R 3초로 종반 처형합니다.
- 결과는 개별 탈출·희생과 탈출 인원을 표시합니다. 재접속 유예 30초. 게임 진행 중 신규 참가 제한. 탈락·탈출 후 관전 가능.

## 맵

`map.js`의 BLACKPINE 폐쇄 벌목장: 중앙 산장, 숲속 오두막, 소나무 숲, 폐차장, 무너진 작업장, 목재 적재장. 주요 건물·출입구·통로는 직접 배치하고, 시드마다 추격 타일 종류와 발전기 배치를 바꿉니다. 창문·파레트·캐비넷·갈고리·아이템 상자가 서로 연결됩니다. `public/scene.js`가 바닥·목재·돌·차량·나무·그림자·시야 가림을 그립니다.

## 장비

구급상자(자기 치료 기본 24초), 공구상자(수리 +50%, 사용량 32), 손전등(조준해 눈을 멀게 함, 사용량 8). E 10초로 상자를 열면 새 아이템을 얻습니다. 손전등은 거리·시야·조준과 살인마 방향을 확인합니다.

오리지널 특전 6종: 생존자 정비 숙련(+5% 수리), 응급 처치(+15% 치료), 생존 본능(달리기 시작 +50% 3초, 탈진 40초); 살인마 철거 숙련(+15% 파괴), 끈질긴 추적(흔적 +4초), 야간 순찰(갈고리 후 +10% 이동 8초). 역할에 맞는 특전만 선택 가능합니다. 대기실에서 선택 후 '장비·특전 적용'을 누릅니다.

## 채팅과 디버깅

작은 반투명 채팅창 제목을 드래그해 이동합니다. 생존자와 사망자 채널을 서버에서 분리하며 살인마는 읽기·전송 모두 불가합니다. 탈출한 관전자는 생존자 채널을 유지합니다. 메시지 200자·최근 50개·전송 간격 제한.

이름을 정확히 admin으로 입력하면 T 전체 맵, B 충돌 영역, O ID, I 패널, 휠 확대·드래그·상태 JSON 확인 기능을 사용할 수 있습니다. 일반 플레이어에게 벽 뒤/시야 밖 좌표와 숨은 캐비넷 점유자를 보내지 않습니다. 생존자에게는 빈사·갈고리 동료의 구출 오라를 제공합니다. 누구나 admin 이름을 사용할 수 있으므로 인증 관리자 권한은 아닙니다.

## 통합 배포 및 검증

`node scripts/integrate-concave.mjs C:/Project/Concave`로 실제 Render 배포 저장소 https://github.com/easycd/Concave_Game 의 nightfall/에 동기화합니다. `/nightfall` Socket.IO 네임스페이스를 기존 서버에 연결합니다. 새 주 서비스: playgame (`srv-db3eeemi0phs739r55f0`), 무료 Singapore, 자동 배포 꺼짐. 기존 omok-sai 서비스는 별도 방을 가진 구 주소입니다.

`npm test`: 규칙·25개 맵 시드의 목표 접근성·실제 소켓·시야·재접속·채팅 검증. `npm run check`: 소스 구문 검사. 오목 프로젝트 `npm test`, `npm run build`: 통합 회귀 검증.

## 구현 범위

일반 1대4의 공통 플레이 흐름을 이식한 2D 버전입니다. 원작의 모든 캐릭터·특전·아이템·애드온·공물·경제·토템·이벤트 모드까지 동일하게 복제한 제품은 아닙니다. 고유 능력 없는 기본 공격 살인마와 오리지널 특전 6종은 사용자가 선택한 범위입니다. 스킬 체크는 서버 타이밍으로 판정하며 운반 저항 UI, 공격 거리, 시야, 맵 크기는 2D에 맞춰 조정했습니다. 닉네임·비밀번호 계정과 역할별 캐릭터 색상 저장을 지원합니다. 자세한 저장소 설정은 [ACCOUNTS.md](ACCOUNTS.md)를 참고하세요. 매치메이킹과 블러드웹 같은 영구 성장은 포함하지 않습니다. 연결이 끊긴 생존자는 유예 시간 뒤 대체 봇이 이어서 플레이합니다. 방은 단일 서버 메모리에 저장되며 재배포 시 초기화됩니다.

## 원작 이동 비율에 맞춘 숲 맵 (2026-10-15)

104×96m, 9,984㎡의 일반 1대4 야외 맵 규모입니다. 달리기 4m/s를 기준으로 1m=42.5px, 월드 4420×4080px를 사용합니다. 생존자는 장애물 없는 가로 직선 26초, 세로 24초에 달립니다. 나무 약 600–800그루, 덤불 약 300개, 지면 식생·장식 약 8,700개를 배치하며 수량은 시드에 따라 달라집니다. 산장/오두막 3개, 숲 추격 구간 12개, 파레트 15개, 갈고리 8개, 캐비넷 16개를 연결합니다. 7개 발전기는 여섯 구역에 하나씩 배치하고 나머지 하나도 분산 조건에 맞춰 배치하며 탈출구 2개는 반대편에 있습니다.

나무 줄기는 이동과 시야를 막지만 잎과 지면 장식은 이동을 방해하지 않습니다. 스폰·목표 주변 접근 공간을 보호하고 25개 시드에서 도달 가능성을 검사합니다. 화면 밖 오브젝트는 그리지 않으며, 전체 맵 축소 보기에서는 지면 장식을 일부 생략합니다.

원작의 맵 면적은 위키 운영진의 실측을 참고한 값이며, 특정 원작 지도의 구조나 가로·세로를 그대로 복제한 것은 아닙니다. 비교 기준과 계산은 [MAP_SCALE_RESEARCH.md](MAP_SCALE_RESEARCH.md)에 기록했습니다.

## 경기마다 랜덤 배치

탈출구 2개의 좌표는 고정합니다. 새 경기에서는 건물·벽·창문·파레트·캐비넷·발전기·갈고리·상자·해치·나무·덤불·지면 장식·스폰 및 숲길을 새 시드로 생성합니다. 건물은 구역을 나누어 배치하며, 추격 구간은 위치와 회전 방향이 바뀝니다.

기본 7개 발전기는 3열×2행의 여섯 구역에 최소 하나씩, 발전기 사이 600px(약 14.1m) 이상의 간격으로 배치합니다. 추가 발전기는 한쪽 절반에 5개 이상 또는 한 열에 4개 이상 모이지 않게 합니다. 작은 방의 5/6개 발전기도 양쪽 절반과 세 열에 분산됩니다. 갈고리는 네 구역에 두 개씩, 상자는 세 열에 하나씩 그리고 위/아래 양쪽에 배치합니다. 모든 플레이어 스폰은 살인마 스폰과 최소 850px 떨어지고 생존자끼리도 230px 이상 떨어집니다.

같은 시드는 같은 배치를 재현해 admin 디버깅에 사용할 수 있습니다. 주요 대상과 스폰의 접근 통로는 확보하고 식생을 생성합니다. 100개 배치의 분산·간격과 25개 배치의 전체 목표/스폰 이동 경로를 자동 검사합니다.
